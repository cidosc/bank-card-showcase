用途：同一张卡面并排对比 4 种效果（normal / holographic / glitter / silver）在不同明暗卡面上的曝光表现，检查是否过曝（发白、细节丢失）或 过暗（发灰、图案发闷）。鼠标移到卡面上即可看到真实倾斜与反光；页面顶部可切换质感、效果强度与倾角。

卡面素材说明：①②③ 为项目自制的临时占位卡面（npm run assets 可复现）； ④ 为项目负责人提供的本地测试图（位于 test-assets/，不随交付产物发布，仅用于本地检验特效在真实感美术上的表现）。 换成你自己的正式卡面后，请重新目视复核一次——深色卡与浅色卡的曝光表现不同。
